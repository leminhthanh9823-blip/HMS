# RBAC — Role, Permission and Approval

Purpose: function/property-scoped authorization, thresholds and maker-checker approval. System Admin does not receive business-operation authority. (BA Part 2, pp.16–21, 30–32.)

FR-RBAC-001–012 cover roles/permissions/property assignment, threshold checks, Approval lifecycle, remote/counter approval, separation of duties, cross-property denial and immediate revocation. (BA Part 2, pp.16–17.)

Key rules: BR-060–061, BR-064–065, BR-068–069. Approval freezes value/version and cannot silently execute after object change. Open: one-person operation OQ-040, approval expiry OQ-042, 2FA OQ-043 and device/PIN OQ-044. (BA Part 2, pp.17–21, 41–42.)
