# EMP — Employee and Account

Purpose: individual employee account, property-role assignment, invitation/activation, authentication/session and immediate deactivation. Basic shift assignment is in scope; payroll/detailed timekeeping is not. (BA Part 1, p.8; Part 2, pp.22–26.)

FR-EMP-001–009 cover employee invitation/profile/status, password/2FA/PIN, login/session/lockout/recovery, stop/revoke and multi-property assignment. (BA Part 2, pp.22–23.)

Key rules: BR-061, BR-065; security refinements NFR-SEC-101+. Open: multi-property roles OQ-041, 2FA OQ-043, counter/personal devices and PIN OQ-044. (BA Part 2, pp.23–26, 38–42.)
